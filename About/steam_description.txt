[h1]RimSynapse - NVIDIA Tool[/h1]
[b][url=https://github.com/RimSynapse/NVIDIA-Tool/wiki]Official Wiki and Documentation[/url][/b]

[b]Real-Time GPU Monitoring and LLM Performance Dashboard for RimSynapse.[/b]

This developer and power-user tool provides a comprehensive overview of your local GPU's health, VRAM usage, and LLM request performance — all rendered directly inside RimWorld's UI.

---

[h2]Core Systems[/h2]
[list]
[*] [b]Live GPU Monitoring:[/b] Reads NVIDIA GPU stats via nvidia-smi in real-time. Displays VRAM usage, GPU temperature, utilization percentage, and power draw.
[*] [b]VRAM Breakdown:[/b] Shows a detailed breakdown of estimated VRAM consumption: model size, KV cache, context window, and overhead. Helps you understand exactly where your GPU memory is going.
[*] [b]VRAM Warnings:[/b] Proactive alerts when your GPU is approaching VRAM limits, with recommendations for model sizes and context window adjustments.
[*] [b]Request Metrics:[/b] Tracks every LLM request made by RimSynapse mods — response times, token counts, throughput (tokens/second), and queue depth. Identifies bottlenecks in your AI pipeline.
[*] [b]In-Game Overlay HUD:[/b] A toggleable on-screen overlay that displays GPU stats, request queue status, and active model information without opening any menus.
[*] [b]Developer Tools Window:[/b] A comprehensive debug window with tabs for GPU stats, request history, VRAM analysis, and configuration. Essential for mod developers building on RimSynapse.
[/list]

[h2]Toolbar Integration[/h2]
[list]
[*] [b]Quick Toggle:[/b] A toolbar button lets you instantly toggle the GPU overlay and open the developer tools window.
[/list]

[h2]Default Settings (adjustable in-game)[/h2]
[code]
  Overlay Enabled:               false  (Toggle the on-screen GPU HUD)
  nvidia-smi Poll Interval:      2000ms (How often GPU stats are refreshed)
  Request History Length:         100    (Number of recent LLM requests to keep in the metrics log)
[/code]
